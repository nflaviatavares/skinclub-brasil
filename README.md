# Skin Club Brasil — Website Oficial (Rascunho / Draft)

Site institucional e página Sobre Nós para o **Skin Club Brasil**, desenvolvido com estética editorial inspirada no *Nakie Face*.

---

## 🚀 Como publicar no GitHub Pages (Passo a Passo)

1. Crie um novo repositório no seu GitHub com o nome (por exemplo: `skinclub-brasil`).
2. Defina o repositório como **PÚBLICO** (necessário para o GitHub Pages gratuito).
3. No terminal desta pasta, execute os comandos:
   ```bash
   git branch -M main
   git remote add origin https://github.com/SEU_USUARIO/skinclub-brasil.git
   git push -u origin main
   ```
4. No GitHub, acesse:
   **Settings** > **Pages** (no menu lateral esquerdo)
5. Em **Branch**, selecione `main` e a pasta `/(root)`, depois clique em **Save**.
6. Em cerca de 1 minuto, o GitHub gerará o link oficial:
   `https://SEU_USUARIO.github.io/skinclub-brasil/`

---

## ⚡ Alternativa 100% Privada (Vercel ou Netlify)

Se você preferir manter o código em um repositório **Privado**:
1. Suba o repositório como **Privado** no GitHub.
2. Acesse [vercel.com](https://vercel.com) ou [netlify.com](https://netlify.com).
3. Clique em **Add New Project** e selecione o repositório `skinclub-brasil`.
4. Clique em **Deploy**. O site ficará no ar com um link como `skinclub-brasil.vercel.app` sem expor o código-fonte.
